Unifique PDP - Backend

API básica em Node.js + Express

Scripts:
- npm run dev -> inicia nodemon
- npm start -> inicia node

Configurar variáveis de ambiente com .env (use .env.example como modelo)

Rotas iniciais:
- GET / -> status API
- POST /projects -> criar projeto (mock)
- GET /projects/:id -> obter projeto (mock)
- POST /auth/login -> autenticação (mock)
